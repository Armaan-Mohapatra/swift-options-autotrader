# Dependency audit, 2026-11-21 (SEC-006 remediation)

Scope: the universal `uv.lock` exported for the `dev`, `telegram` and `paper-market` extras
(`uv export --locked --no-hashes`), plus the `uv==0.10.0` bootstrap installer.

## Inventory and SBOM

- 50 locked components, CycloneDX 1.6: `docs/audits/20261121_SBOM_CYCLONEDX.json`
  (generated by cyclonedx-bom 9.0.0 from the exported requirements).
- Lock audit (`scripts/audit_lock.py`): 50 packages, 711 hashed artifacts, passed on Python 3.11 and 3.13.

## Vulnerability audit

- `pip-audit 2.10.1` against the 46 exported requirement pins (`--no-deps --disable-pip`):
  **no known vulnerabilities**. Run live against the public vulnerability sources on 2026-11-21.
  This is a point-in-time result. It is not a signed attestation and is not repeated in CI.
- Limits: pywin32 is Windows-only and is not resolved on macOS. The pip-audit run used the
  exported pins, not the installed artifacts. Licence review is unchanged from `DEPENDENCIES.md`.

## uv bootstrap (SEC-006)

- Previously: `pip install 'uv==0.10.0'` with no artifact hash.
- Now: `requirements/uv-bootstrap.txt` pins all 18 PyPI artifacts of uv 0.10.0 by SHA-256,
  installed with `--require-hashes --only-binary=:all:`. `setup.ps1` embeds the identical list,
  and CI uses the requirements file. `tests/unit/test_uv_bootstrap_pin.py` enforces both.
- Digests come from PyPI's JSON API over TLS. The Windows `win_amd64` wheel was downloaded and
  hashed locally: `edd469425cd62bcd8c8cc0226c5f9043a94e37ed869da8268c80fdbfd3e5015e`, which matches.
- Not verified: PyPI's Sigstore/PEP 740 attestations for uv 0.10.0, and an independent
  second-source comparison of the digests. Both remain open residual risks.
